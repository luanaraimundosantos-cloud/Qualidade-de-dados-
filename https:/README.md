# Ciência de Dados: Prevendo Padrões de Qualidade de Vida da Turma

Projeto desenvolvido para a unidade de Ciência de Dados da plataforma Start by Alura.

## Funcionalidades
1. **Estatística Descritiva:** Cálculo de Média, Mediana e Desvio Padrão.
2. **Distribuição Gaussiana:** Simulação estatística de dados em larga escala.
3. **Modelagem Preditiva:** Classificação de padrões individuais em relação à curva da turma.

## Como Executar
Certifique-se de ter o Python instalado. No terminal, execute:

```bash
python main.py
